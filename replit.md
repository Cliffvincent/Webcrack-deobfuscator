# Xenon Booster

## Run locally on Replit

```bash
npm run dev
```

The Express server listens on port `8080`. The main workflow is **Start application**.

## Current ordering flow

- The **New Order** screen loads the live provider service catalog.
- Use the platform buttons, category dropdown, or **Search services...** field to narrow the services shown in the order selector.
- Services are grouped by category in the selector.
- The separate **Services** tab keeps its own search and category filters.
